# The Governance Deck

Forty cards for executives and boards approving and overseeing AI, distilled
from the generic frameworks of the Leading AI with Confidence course. Free
product: no gate, no capture.

**Live:** https://michael-borck.github.io/governance-deck/
**Repo:** https://github.com/michael-borck/governance-deck

**The tools change. Accountability does not.**

## The design

One organic size: 40 cards — The Line (8), Oversight (10), Data (8), Vendors
(8), Learning (6). One card type: why it goes wrong, the move, the line. Every
move ends in an owner, a piece of evidence, or a review date.

NDA note: generic frameworks only. No ERS-tailored material. See
`source/README.md`.

## deck/

| File | What it is |
|---|---|
| `governance-deck-40-cards.md` | The deck, markdown. |
| `governance-deck-40-print.html` | Print & cut. 6 A4 pages, 8 cards per sheet, cover card first. |
| `governance-deck-40-art.html` | Art edition for the boxed print run: portrait cards, 6 per A4, category vignette tinted per colour on every face. |
| `governance-deck-guide.html` | One-page diagnostic: fifteen checks for the organisation. |
| `governance-facilitation.html` | Sixty-minute session sheet: tiers, red lines, vendor gap, review dates. |
| `governance-desk-card.html` | One A4 pin-up: the core five, the test, default-up. |
| `fonts/` | Domine, Funnel Sans, Nanum Gothic Coding (SIL OFL). |

Art: `assets/art/` holds the boardroom-chiaroscuro identity — cover, back,
banner and five category vignettes, generated with limn (SwarmUI,
juggernautXL_v9). Prompts and the locked style prefix are in
`assets/art/README.md` and the `.png.json` sidecars.

## Print setup

A4, 100% scale, background graphics on. Cut along the dashed lines.
